How to take a range

  1. 1
    ReserveOpen a GitHub issue with the range you want, for example “PRP 3,600,000 – 3,610,000” or “sieve p 1–2 × 1012”. You get a worktodo file back.
  2. 2
    RunPut the file in Prime95 or Mass Prime Siever. The lines look like the examples here.
  3. 3
    Send resultsUpload Prime95’s results.json.txt with the first form below. Proof files are only needed when a test reports a probable prime; the form asks for them then. Sieve output (results.json, with siever.log if you have it) has its own form. Every factor in it is checked before an n is struck out, and overlapping work from several machines is merged, so it does no harm.
  4. 4
    Get creditResults appear on the exponent pages under the name you choose. A reported prime shows as being verified while the project re-runs the test; then it goes to the OEIS and the PRP Records list with your name.

Example work lines

worktodo.txt for Prime95 30.19 or later

PRP=1,2,n,-25

Each line tests 1 × 2n − 25. Prime95 writes one JSON line per test to results.json.txt; that file is what you upload.

Upload sieve output

checking the upload server…

Send the results.json that Mass Prime Siever writes, with siever.log from the same folder if you have it. Your browser first checks every factor: it must divide 2n − 25, be prime and lie in the file’s p range, and every odd n must appear exactly once. Then only the n that have a factor are sent, and the server checks each factor again as it arrives.

About the project

The search looks for n where 2n − 25 is prime, sequence A379020 in the OEIS, and aims for a prime of about two million digits.

Data files

Every number on this site comes from static JSON files, rebuilt from the result files after each batch of work. They are free to reuse.

  • data/summary.jsontotals, frontier, latest results and daily counts
  • data/ranges.jsonone row per 0.2M of n: sieve depth, survivors, P-1 and PRP counts
  • data/primes.jsonevery known n: who found it first and when, and this project’s test
  • data/sieve.jsonP-1 factor sizes and the survivor constant per range
  • data/progress.jsonthe big chart on the Status page: per 25,000 n, what the sieve, P-1 and PRP left, and P-1 factors by size
  • data/site.jsonplans, sieve assignments and notes written by hand
  • data/n/3.5.jsonone file per 0.1M of n: every sieve survivor with its P-1 and PRP records
